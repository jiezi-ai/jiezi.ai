## AI 编程工具

### 编辑器 / IDE 插件

| 工具 | 平台 | 特点 |
|------|------|------|
| [Claude Code](https://docs.anthropic.com/en/docs/claude-code) | CLI | 终端 Agent，自主完成复杂任务 |
| [Cline](https://github.com/cline/cline) | VS Code | 开源，支持多模型 |
| [Roo Code](https://github.com/RooVetGit/Roo-Code) | VS Code | Cline fork，更多自定义 |
| [Cursor](https://cursor.com) | 独立编辑器 | 集成体验好，需自己订阅 |
| [Windsurf](https://codeium.com/windsurf) | 独立编辑器 | Codeium 出品 |

### API 平台

| 平台 | 说明 |
|------|------|
| [OpenRouter](https://openrouter.ai) | 多模型聚合，一个 Key 调用所有模型 |
| [MiniMax](https://platform.minimaxi.com) | 解字计划当前供应商 |

## 开发基础工具

| 工具 | 用途 | 安装 |
|------|------|------|
| [VS Code](https://code.visualstudio.com) | 代码编辑器 | 官网下载 |
| [Git](https://git-scm.com) | 版本控制 | `brew install git` / `apt install git` |
| [GitHub CLI](https://cli.github.com) | GitHub 命令行 | `brew install gh` |
| [Node.js](https://nodejs.org) | JavaScript 运行时 | 推荐用 [fnm](https://github.com/Schniz/fnm) 安装 |
| [Python](https://python.org) | Python 运行时 | 推荐用 [uv](https://github.com/astral-sh/uv) 管理 |

## 部署平台

做了项目想让别人用？这些平台可以免费部署：

| 平台 | 适合 | 免费额度 |
|------|------|----------|
| [Vercel](https://vercel.com) | 前端项目、Next.js | 个人免费 |
| [Cloudflare Pages](https://pages.cloudflare.com) | 静态站、Workers | 免费额度充足 |
| [GitHub Pages](https://pages.github.com) | 静态站 | 完全免费 |
| [Railway](https://railway.app) | 后端服务 | $5/月免费额度 |
| [Fly.io](https://fly.io) | 容器部署 | 免费 tier |
